Project Proposal

Title: Remote-Controlled Toy Car

This project involves creating a remote-controlled toy car using an Arduino Uno board.(update: I used an ESP32S3 board instead to enable bluetooth connection)


Anticipated Bill of Materials:


- Red and green LED (indicating the operational status of the car)
- Remote control/receiver
- DC motor (for power)
- Servo motor (for steering)
- H Bridge (for throttle control)
- Assorted resistors (for current-limiting)
- Some 3D printed parts (for the structure of the car)


Timeline and contingency plans:


- RC controller being able to control DC motor and Servo motor
- Powertrain working
- 3D printed car model complete
- If something goes wrong with the powertrain (transmission, differential, etc), I will use four motors instead of two so they can be connected directly into the wheel.

this is the final project setup. The toy car is controlled by a remote control that communicates with the Arduino Uno board. The car has DC motors for movement and a servo motor for steering.
